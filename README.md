🌐 HTML Portfolio Project

A beginner-level portfolio website built using pure HTML, designed to practice and demonstrate the fundamentals of HTML structure and elements.
This project focuses on semantic markup, basic navigation, forms, images, and content organization without using CSS or JavaScript.

✨ Features

Basic navigation bar using unordered lists
Header section with name, introduction, and call-to-action link
Image usage with proper alt attributes
Ordered and unordered lists for content organization
Social media links section
Image gallery section
HTML form with input fields and validation types
Internal and external page linking


🛠️ Technologies Used

HTML5 only
(No CSS or JavaScript used — intentionally kept simple)

📚 Concepts Practiced
HTML document structure (<!DOCTYPE>, <head>, <body>)
Semantic elements (<nav>, <header>, <section>, <form>)
Lists ( <ul> , <ol> )
Links ( <a> )
Images ( <img> )


Purpose of the Project

This project was created to:
Learn and apply HTML basics
Understand webpage structure
Practice content layout without styling
Build confidence before moving to CSS and JavaScript
Serve as a foundation portfolio project
